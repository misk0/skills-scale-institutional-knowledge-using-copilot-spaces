# OctoAcme Project Management Docs

This README provides a guide and index to the project management process documentation for OctoAcme. Use the links below to find detailed guides for each phase of the project lifecycle, plus role definitions and checklists for quality and execution.

## Summary of OctoAcme Project Management Processes

OctoAcme delivers cross-functional projects with a structured, iterative approach:

- **Initiation:** Define problem, objectives, stakeholders, and measurable success criteria. Align on business need and establish a Project One-pager.
- **Planning:** Break work into shippable increments, prioritize backlog, align on timelines, risks, and responsibilities. Define acceptance criteria and Definition of Done.
- **Execution & Tracking:** Track progress with daily standups, project boards, and delivery syncs. Emphasize small PRs, test coverage, regular demos, and team rhythm.
- **Risk Management & Communication:** Identify, mitigate, and monitor risks. Keep stakeholders informed with regular status updates, escalation paths, and incident playbooks.
- **Release & Deployment:** Gate releases behind quality checks, CI/security scans, and review. Use checklists to ensure safe, well-communicated deployments and rollback plans.
- **Retrospectives & Continuous Improvement:** Capture learnings after each milestone or release. Raise and track team action items to drive ongoing improvements.
- **Roles & Expectations:** Defined PM, PdM, Developer, and QA responsibilities; clear expectations for communication and success metrics.

## Core Principles

- **Customer-first:** Prioritize customer value and usability
- **Iterative delivery:** Deliver small, testable increments
- **Clear ownership:** Each project has a named Project Manager and Product Lead
- **Data-informed decisions:** Measure impact and iterate based on evidence
- **Psychological safety:** Encourage feedback and learning

## Quick Start for New Team Members

1. Start with [Project Management Overview](octoacme-project-management-overview.md) to understand the big picture
2. Review [Roles & Personas](octoacme-roles-and-personas.md) to find your responsibilities
3. Consult specific phase guides (Initiation, Planning, Execution, etc.) as needed for your work
4. Use checklists and templates within each guide for consistent execution

## Key Artifacts to Maintain

- Project Charter / One-pager
- Roadmap and Release Plan
- Sprint/Iteration Backlog
- Acceptance Criteria & Definition of Done
- Risk Register
- Retrospective notes and action items

## Communication Cadence

- **Daily:** Team standups (15 min focus on progress, blockers, dependencies)
- **Weekly:** PM + PdM sync; team delivery syncs
- **Milestone-based:** Demo/Review at the end of each sprint or milestone
- **Monthly:** Stakeholder updates
