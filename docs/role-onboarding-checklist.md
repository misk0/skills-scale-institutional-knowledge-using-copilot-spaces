# Role Onboarding & Accountability Checklist

This checklist helps ensure responsibilities and handoffs are clear when a role is introduced to a project.

- [ ] Role owner identified (name & contact)
- [ ] Role responsibilities documented in repo docs
- [ ] Primary interactions & handoffs documented (who, when, what)
- [ ] Acceptance criteria for role deliverables defined
- [ ] Dashboards / metrics assigned (owner + access)
- [ ] Access & tooling configured (repos, dashboards, CI, etc.)
- [ ] Release readiness / compliance gates documented (if applicable)
- [ ] Review scheduled with stakeholders to confirm role clarity

Suggested reviewers for this change:
- Product Manager
- Project Manager
- Engineering Lead
- QA / Testing
- Customer Success (if customer-facing)
